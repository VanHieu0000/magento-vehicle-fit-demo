Chapter 03 · how it fits together

Four parts. Zero session cookies.

1

Pick

Ajax dropdowns: make, model, year / engine. Answers are the same for every visitor, so even they cache at the edge.

vehiclefit/ajax/options
2

URL

Choice goes into the URL, not the session. Each vehicle page is a normal cacheable page.

?vehicle=12
3

Filter

A plugin on the catalog layer keeps only linked products. Indexed table + tagged app cache.

LayerFilterPlugin
4

Purge

CSV import cleans one cache tag. Varnish / Fastly purge only fitment pages, not the whole store.

clean_cache_by_tags

Chapter 06 · speed

Fast because it stays out of the way.

No session for guests

Picking a car never starts a PHP session, so the page has no Set-Cookie and the CDN can keep it.

No cacheable="false"

Not one block disables full page cache. Personal bits (badge) load by ajax after the page.

Purge by tag

Pages carry the hieu_vehiclefit tag. One import purges them, nothing else.

example output
$ curl -sI "https://yourstore.com/brakes.html?vehicle=12" | grep -iE "cache|age|set-cookie"
